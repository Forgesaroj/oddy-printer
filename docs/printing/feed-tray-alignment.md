# Feed Tray Positioning and Grain Direction Alignment

## Paper Grain Direction and Feed Orientation

Understanding paper grain is essential for wrinkle-free, jam-free label printing.

### Grain Direction Basics
- **Grain Long (GL):** Fibers run parallel to the 297mm length of A4.
- **Grain Short (GS):** Fibers run parallel to the 210mm width of A4.
- Oddy label sheets are manufactured **Grain Long**. This provides maximum dimensional stability and resistance against buckling when fed short-edge-first into laser printers.

### Feed Orientation Rule
- Always insert sheets **Short Edge First (SEF)** into the manual bypass feed tray.
- Adjust the green/blue plastic width guides until they contact both edges of the sheet with zero lateral play.
