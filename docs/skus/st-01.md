# Oddy ST-1 A4100 Sticker Sheet Specification

## Overview
- **SKU Code**: `ST-1 A4100`
- **Total Labels per Sheet**: 1
- **Layout Grid**: 1 column × 1 row (Full A4 Sheet)
- **Label Dimensions**: 199.6 mm × 289 mm
- **Avery Equivalent Reference**: L-7167

## Recommended Applications
- Full-page parcel and shipping crate labels.
- Inventory bin master sheets.
- Signage and warning notices.

## Print Alignment Tips
- Ensure browser print scale is set to strictly **100% (Actual Size)**.
- Margins must be set to **None**.
