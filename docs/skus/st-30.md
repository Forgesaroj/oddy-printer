# Oddy ST-30A4100 A4 Sticker Sheet Specification

Detailed technical specification and printing configuration for **Oddy ST-30A4100** (30 Compact 5-Column Product Labels).

---

| Parameter | Value (Metric) | Notes & Calibration |

| **Software Equivalent** | `Custom` | Standard Word / gLabels template code |

## 2. Recommended Industry Applications

The **ST-30A4100** format is engineered for high-precision labeling:
- **Retail & Supermarkets:** Standard SKU barcode tags, MRP stickers with VAT/PAN details, shelf pricing.
- **Logistics & Warehousing:** Carton identification, bin location tags, dispatch sorting markers.
- **Office & Document Management:** Binder spine indexing, folder classification, mailing lists.
- **Healthcare & Pharmaceuticals:** Sample tube labels, batch tracking, prescription dosing instructions.

## 3. Browser Print Calibration (`@media print`)

To achieve millimetric accuracy on standard A4 paper, apply the following CSS layout:

```css
@page {
  size: A4 portrait;
  margin: 0;
}

.sheet-container {
  width: 210mm;
  height: 297mm;
  padding-top: 6.0mm;
  padding-left: 7.5mm;
  display: grid;
  grid-template-columns: repeat(5, 39.0mm);
  grid-template-rows: repeat(6, 47.5mm);
  column-gap: 1.5mm;
  row-gap: 0.0mm;
  box-sizing: border-box;

  width: 39.0mm;
  height: 47.5mm;
  overflow: hidden;
  box-sizing: border-box;
  page-break-inside: avoid;
}
```

## 4. Hardware Printer Setup & Feed Guidance

1. **Feed Tray:** Always load sticker sheets via the **Manual Bypass / Multipurpose Tray**. Avoid bottom paper cassettes because tight 180° roller bends can separate peelable labels inside the transport assembly.
2. **Paper Weight Profile:** Set your printer driver media type to **"Labels"**, **"Heavyweight (120–160 g/m²)"**, or **"Thick Paper"**. This reduces belt speed and ensures adequate fuser drum heat (180°C+) to permanently fuse toner onto silicone release liners.
3. **Browser Print Dialog:**
   - **Scale:** Strictly **100% (Actual Size)**. Never use "Fit to printable area" or "Fit to page" (which shrinks content by 3–7%).
   - **Margins:** Set to **None** or **Custom (0)**.
   - **Options:** Uncheck "Headers and Footers" to prevent URL and date timestamps from overlapping label boundaries.
